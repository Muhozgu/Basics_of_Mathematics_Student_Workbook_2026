# Solution 5

Recall that a matrix is symmetric if $M^T=M$, and skew-symmetric if
$M^T=-M$.

| Matrix | Classification |
|---|---|
| $D=\begin{pmatrix}3&0\\0&3\end{pmatrix}$ | Diagonal and scalar; consequently, it is also symmetric. |
| $S=\begin{pmatrix}1&-2\\-2&5\end{pmatrix}$ | Symmetric, since its off-diagonal entries are equal. |
| $K=\begin{pmatrix}0&4\\-4&0\end{pmatrix}$ | Skew-symmetric, since $K^T=-K$. |

For the remaining matrices:

| Matrix | Classification and dimensions |
|---|---|
| $T=\begin{pmatrix}2&1\\0&3\end{pmatrix}$ | Upper triangular; it is $2\times2$. |
| $I_2$ | Identity matrix of order $2$ (and also both upper and lower triangular); it is $2\times2$. |
| $0_{2\times3}$ | Zero matrix with $2$ rows and $3$ columns; it is $2\times3$. It is not triangular, since triangular matrices are square. |
