# Solution 6

We classify each system.

### (a)

$$
\begin{cases}x+2y=3\\2x+4y=6\end{cases}
$$

The second equation is just twice the first equation:

$$
2(x+2y)=2x+4y=6.
$$

So the two equations are dependent and represent the same line. The system has infinitely many solutions.

Write the solution set as

$$
 x+2y=3\quad\Rightarrow\quad x=3-2t,\quad y=t,\quad t\in\mathbb{R}.
$$

Thus

$$
\boxed{\{(3-2t,t):t\in\mathbb{R}\}}.
$$

### (b)

$$
\begin{cases}x+2y=3\\2x+4y=7\end{cases}
$$

If the second equation were a multiple of the first, it would have to equal $2(x+2y)=6$, but it equals $7$. This is impossible.

Therefore the system is inconsistent and has no solution:

$$
\boxed{\varnothing}.
$$
