# Exercise 4 Solution

## Problem
Without expanding the determinant, compute
$$
\det\begin{pmatrix}2&4&1\\0&-3&5\\0&0&7\end{pmatrix}.
$$
State the rule for an arbitrary triangular matrix and explain it using this example.

## Solution
This is an upper triangular matrix. For any triangular matrix, the determinant is the product of the diagonal entries.

So,
$$
\det = 2\cdot(-3)\cdot7=-42.
$$

This matches the general rule: for a triangular matrix, all entries below or above the diagonal are irrelevant to the determinant; only the diagonal entries matter.

## Final Answer
$$
\det\begin{pmatrix}2&4&1\\0&-3&5\\0&0&7\end{pmatrix}=-42.
$$
